# SocietyLab v1.4 — 解釈は歴史に到達するか

小さな村のエージェントベース・シミュレーション(Python)です。
問いはひとつだけです。

> **「出来事をどう解釈したか」という心の中の差は、確率的に実現する歴史(誰が死に、誰が生まれ、村がどうなるか)にまで届くのか?**

v1.4はその検証のために作られた「大元」のモデルです。宗教・イデオロギー・権威といった変数は一切持っていません。持っているのは、記憶・信頼・声・解釈という最小限の素材だけです。そこに**たった3%の解釈ナッジ**を入れて、80年間の歴史が曲がるかどうかを観察しました。

この研究は人間1名と複数のAI(Claude / ChatGPT / Codex / Grok)の共同作業で行われ、互いの結果を相互監査しながら進めました。

---

## 結論(先に言います)

> **微小な解釈ナッジは、歴史を動かす力としてはほぼ消える。しかし完全には消えない。**
> RNG分離という厳しい検査の後にも、「支持→プロジェクト→資源→死亡」という社会チャネルを通った微小な差分(80年で最大2人、平均0.5人)が一部のseedに残る。これは強い因果でも純粋なノイズでもなく、**高影響人物が支持の閾値近傍にいるときだけ通過する「経路残渣(path residue)」**である。

派手な結果ではありません。むしろ、最初に見えた派手な結果(100seed中38seedが分岐、人口差最大14人)の大部分が**乱数の簿記アーティファクトだった**ことを突き止め、本物の残渣だけを取り出したのがこの研究の本体です。

---

## モデルの系譜

v1.4は一晩でできたものではなく、1段ずつ積んだ5世代目です。

| バージョン | 足したもの |
|---|---|
| v1.0 | 信頼ネットワーク |
| v1.1 | 協力と失敗 |
| v1.2 | 声の重み(voice_weight) |
| v1.3 | 解釈の種 — 出来事の解釈が**観測されるだけ**(行動には影響しない) |
| **v1.4** | **解釈が行動を薄く動かす** — 解釈バイアスが提案選択と支持判断に+0.03だけ介入 |

v1.3とv1.4の差分は「解釈→支持の橋」1本だけです。介入の最小性が、後のすべての主張の前提になっています。

---

## 世界の仕組み

30〜40人ほどの村を80年走らせます。外部依存なしの素のPythonです。

**エージェントの属性**: 年齢・性別・health・hunger・fear・charisma・voice_weight・他者への trust、そして解釈バイアス3種(**spiritual / practical / blame**)。

**1年のサイクル**は、おおまかにこの循環です。

```text
危機・死・プロジェクト
→ 記憶 (intensity / decay / interpretation / generation つきで伝わる)
→ 解釈
→ trust / 支持 / 提案
→ プロジェクトの成功・失敗 (store_food, dig_well, tea_house, hunt_group)
→ fear / hunger / 食料 / 死 / 出生
→ また記憶へ
```

モデルの心臓部は `_support_proposals()` です。誰かの提案を支持するかどうかは、trust・charisma・voice・提案の妥当性・fear・乱数の混合で決まります。**v1.4のナッジはここに +0.03 だけ乗ります。** 自分の解釈バイアス(例: blameに傾いた人)と相性のいい提案を、ほんの少しだけ支持しやすくなる。それだけです。

宗教も派閥も権威も変数としては存在しません。それでもログを読むと「語り部」「失敗を背負う人」「静かに縮小する村」のようなものが*見えてしまう*——それがこのモデルの面白さであり、同時に最大の誤読リスクでもあります(後述)。

## 何が起きたか — 3幕構成

### 第1幕: 見かけの効果

結合RNG(全イベントが1本の乱数列を共有する素朴な実装)で100seedを走らせると、ナッジON/OFFで**38/100のseedが分岐**し、最大で人口差14人が出ました。seed1003では「大きく騒がしい村」が「小さく静かでblameに傾いた村」に枝分かれし、ハナという無名の人物(charisma 0.478、信頼されず、Year 28に死亡)が歴史の曲がり角に見える——という強烈な物語まで読めました。

### 第2幕: 崩壊

しかしプラセボ検査(ナッジの代わりに乱数を1回余分に引くだけ)で**100/100のseedが分岐**しました。つまり結合RNG世界の分岐の大部分は、因果ではなく**乱数の消費順がずれたことによる簿記アーティファクト**でした。第1幕の派手な数字とseed物語は、ここでいったん全部捨てます。

### 第3幕: 経路残渣

そこでRNGをストリーム分離(支持・死亡・出生などの乱数を毎年 `hash(seed, year, stream)` で独立に引く)し、簿記アーティファクトを遮断して再検査しました。

| 検査 | 結果 |
|---|---|
| ナッジON vs OFF | **25/100 が分岐** |
| supportプラセボ(1ドロー) | **7/100 が分岐** |
| 分岐したseedの人口差 | **平均0.52人、最大2人**(80年で) |
| seed1036 | 完全identical — 結合世界の分岐が純粋な簿記だった対照例 |
| seed1096 | **因果階段**: Y46プロジェクト差 → Y52食料差 → Y55死亡差。人口が同一のまま死亡確率だけが変わり、同一乱数に対して生死が逆転 |

残った差分は小さい。しかしプラセボ(7/100)とは統計的に区別でき、侵入経路は常に同じ骨格でした。

```text
解釈 → 支持 → プロジェクト選択 → 資源 → 死亡
```

この骨格は、実装の異なる2系統(Claude実装・Grok実装)で独立に収束しました。起点になる人物は10seed横断で重複ゼロ——「ハナが特別」だったのではなく、**charisma ≥ 0.65 または voice_weight ≥ 0.08 の高影響ノードが、支持の乱数閾値の近傍にいたとき**にだけ、残渣が通過します。

## 再現性

中心実験(ナッジ25/100 vs プラセボ7/100)は、凍結したコード4ファイル(SHA-256記録済み)で独立環境において再実行され、**出力JSONのSHA-256が原本と完全同一**——数値一致を超えたバイト単位の再現を確認済みです。乱数がすべて `hash(seed, year, stream)` 由来で消費順に依存しないため、環境が変わっても同一出力になります。

- 実験本体: `ja/src/stream_separation.py`
- モデル本体: `ja/src/society_lab_v1_4.py`
- 接続: `ja/src/bridge.py`
- 結果(原本): `ja/results/stream_separation_results.json`
- 再実行結果: `ja/results/stream_separation_results_rerun_2026-06-11.json`(原本とSHA-256完全一致)
- 監査記録: `ja/results/audit_stream_separation_2026-06-11.md`
- seed範囲: 1000–1099、各80年

## 誤読しないでください

このモデルは物語を読ませる力が強いので、先回りして釘を刺しておきます。

1. **「残渣がある」≠「解釈には社会的因果力がある」。** 残ったのは80年で最大2人の差分です。残渣であって駆動力ではありません。
2. **分岐率(25%等)は頑健な量ではありません。** 率はRNG分離の方式に依存して動きます。頑健なのは率ではなく**侵入の骨格**です。
3. **結合世界の数字(38/100、人口差14人)は使えません。** 簿記アーティファクトと確定済みです。
4. **分岐したseedを解剖すれば、必ず物語が見つかります。** 物語が読めること自体は因果の証拠になりません(生存者選択バイアス)。研究の途中、私たち自身が「seed1003教団」を作りかけました。
5. **効果を出すために変数を足した派生(v2.x系: 蓄積インフラ・協力規範などの増幅器)は、本線から除外しています。** 出た効果は足した設計の反映だからです。
